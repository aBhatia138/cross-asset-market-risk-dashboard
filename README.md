# Cross-Asset Market Risk Dashboard

A Streamlit-based financial analytics application that retrieves historical market data from LSEG Workspace, calculates quantitative risk metrics, and provides natural-language financial analysis through MarketMate, a Groq-powered assistant.

## Overview

The Cross-Asset Market Risk Dashboard combines historical market data retrieval, quantitative risk analysis, interactive visualizations, and an LLM-powered interface.

The application allows users to inspect individual financial instruments, analyze historical price movements, compare assets, and investigate how correlations behave across different market regimes.

MarketMate uses an LLM to interpret natural-language questions and select from a predefined collection of Python tools. Quantitative calculations and market-data retrieval are handled by the underlying Python functions rather than generated by the LLM.

## Features

### 1. Interactive Market Dashboard
- Retrieve historical daily prices from LSEG Workspace.
- Select an instrument using its LSEG RIC.
- Specify a historical observation period.
- View historical price movements and daily returns.
- Export historical price observations as CSV.

### 2. Quantitative Risk Analytics
- Latest available price.
- Latest daily return.
- Annualized historical volatility.
- Maximum drawdown.
- Rolling volatility.
- Historical drawdown visualization.

### 3. Cross-Asset Analysis
- Retrieve and align historical prices across multiple instruments.
- Calculate daily returns.
- Estimate pairwise Pearson correlations.
- Inspect pairwise observation counts.
- Compare correlations across stress and non-stress regimes.

### 4. MarketMate Financial Assistant

MarketMate uses Groq-hosted language models to interpret user questions and invoke approved analytical tools.

Its capabilities include:
- Individual instrument snapshots.
- Multi-asset comparisons and rankings.
- Historical volatility analysis.
- Cross-asset correlation analysis.
- Stress-regime analysis.
- Dashboard-aware questions.
- Interactive analytical visualizations.

## Installation

### Prerequisites

- Python environment compatible with the dependencies in `requirements.txt`.
- Access to LSEG Workspace and the relevant market-data entitlements.
- A Groq API key.

### 1. Clone the repository

```bash
git clone <repository-url>
cd cross_asset_market_dashboard
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root.

Copy the contents of `.env.example` into `.env` and replace the placeholder with your Groq API key:

```dotenv
GROQ_API_KEY=your_actual_groq_api_key
```

The application loads this variable using `python-dotenv`.

**LSEG authentication:** The application opens an LSEG Data Library session through `rd.open_session()`. Users must have the appropriate LSEG Workspace authentication and market-data entitlements configured for their environment.

Never commit `.env` or expose API credentials in source code.

## Running the Application

Ensure that LSEG Workspace is available and authenticated, then execute:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

Select an instrument and historical date range in the sidebar, then click **Fetch historical data** to retrieve the observations and populate the dashboard.

## Automated Testing

Run the complete test suite from the project root:

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

The tests cover quantitative calculations, historical data handling, tool execution, input validation, and MarketMate functionality.

## Data and Access Considerations

- Market data retrieval depends on LSEG Workspace access and applicable entitlements.
- MarketMate's supported instruments are restricted by its configured tool registry.
- The dashboard's RIC input does not guarantee that every instrument is accessible.
- Historical analysis depends on the availability and quality of retrieved observations.
- LSEG data is subject to the applicable licensing and redistribution restrictions.
